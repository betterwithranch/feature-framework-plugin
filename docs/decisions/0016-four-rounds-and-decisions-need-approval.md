# Four review rounds per approved version; decisions need approval

- A level's review has four rounds against the version the user last approved. The work changing the document doesn't reset them.
- Findings are fixed with the level's write skill, including its after-a-fix self-check.
- Fixes that aren't decisions don't need approval; all decisions need approval. A fix is not a decision only when it restores the document to something already agreed and cites it. A new or changed claim, scenario or measure, a reading nothing decided, or dropping something a reviewer objected to is a decision, played back and approved one at a time.
- When the rounds are spent, the work stops and brings the user the findings and a proposed instruction fix. Changing the instructions is the user's decision.
