# 0005. End at working code, verified locally or in CI

Status: accepted, 2026-10-27

## Context

The goal is to go from a prompt to working code without being pulled back in, not a full automation pipeline.

## Decision

Scope ends at working code verified locally or in CI. Deployment, opening PRs and other automation are non-goals for now.
