# 0032. One verification for a requirement that holds across cases

Status: accepted, 2026-11-04

## Context

The user said "assume that we will run all the tests for every level at the end and they must all pass so duplicating is unneeded".

## Decision

A requirement that holds across levels, people or features needs one verification, unless the requirement itself says the cases differ. Asking for a copy of the verification per case is not a review finding.
