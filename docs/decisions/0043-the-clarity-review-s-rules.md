# 0043. The Clarity review's rules

Status: accepted, 2026-11-06

## Context

The user approved these rules as worded (FF-54).

## Decision

1. A reader can tell what result the user gets from the statement, read with the glossary and the rest of the document. It fails only when no reader could tell the result, not when two readers would narrow it differently. 2. The statement uses each term with the meaning the glossary gives it. 3. Each concept has one term throughout the document. 4. The statement contradicts no other requirement, scenario, measure or definition. 5. No other statement makes an exception to an absolute term the script lists in it. Replaces criteria 3 and 6.
