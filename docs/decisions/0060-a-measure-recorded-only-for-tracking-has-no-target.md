# 0060. A measure recorded only for tracking has no target

Status: proposed, 2026-11-09

## Context

Scope rule 4 read "Each measure is taken on real use and has a target." The Outcome's measure of planning misses, the user's own approved measure, says "It's not a pass bar", and [decision 0026](0026-questions-per-level-are-tracked-not-targeted.md) records the user's "we should measure for tracking, but not enforce any expected number of questions".

## Decision

- Scope rule 4 reads: "Each measure is taken on real use. A measure recorded only for tracking needs no target. Every other measure has a target."
- Scope rule 6 reads: "The statement sets no rule, threshold or procedure. A measure recorded only for tracking may say what it counts, and sets no other definition. Every other statement sets no definition. Those belong to a later level."
- Verification rule 6 reads: "A scenario states the expected result. So does a measure that isn't recorded only for tracking. A measure recorded only for tracking needs no expected result."

## Consequences

- Amends the Scope review's rules, [decision 0042](0042-the-scope-review-s-rules.md), and the Verification review's rules, [decision 0044](0044-the-verification-review-s-rules.md).
