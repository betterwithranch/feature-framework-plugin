# 0019. An ambiguity found after code starts is asked

Status: accepted, 2026-10-28

## Context

The Outcome allows clarity questions only before code starts, and also says that after code starts you're asked when blocked by a decision no one made. When something agreed turns out to have two readings after code starts, the two claims disagree.

## Decision

After code starts, choosing between readings of something agreed or codified, when the reading changes the code, is a decision no one made. You're asked, and your answer is written into the record it clarifies. The work never picks a reading on its own.

## Consequences

- The Behaviour document treats such an ambiguity as a decision no one made.
- An ambiguity found after code starts counts as a planning miss.
