# 0048. The glossary review's rules

Status: accepted, 2026-11-06

## Context

The user approved the rule set word for word, "ff-59 a".

## Decision

The project glossary has its own review, run as an isolated judge alongside the level reviews, given the glossary, the conversation, the decision log, the codified rules and the project. It produces a grid of every entry against each rule, PASS or FAIL with a quote. Rules: 1. The entry is something the user said or agreed, or it is marked as the agent's. 2. A reader can tell what the term means from its entry, read with the rest of the glossary. 3. The entry says what its term means and sets no rule, threshold or procedure. 4. Each concept has one term in the glossary. 5. The entry contradicts no other entry. 6. An entry for a term the project already uses gives the project's meaning; where a word of the user's clashes with it, the glossary records the clash.
