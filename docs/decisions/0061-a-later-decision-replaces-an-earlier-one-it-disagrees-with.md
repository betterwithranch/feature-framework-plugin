# 0061. A later decision replaces an earlier one it disagrees with

Status: accepted, 2026-11-09

## Context

The approved Outcome's measure 2, "Decisions in the code that nothing agreed or codified covers: target zero", predates the classification of who decides ([decision 0030](0030-one-classification-of-who-decides.md)), under which the work makes its own decisions. The classification didn't say that a later decision of the user's replaces an earlier one it disagrees with when it doesn't name it, so the measure read as still current and the two read as a conflict for the user to settle (FF-68). The user withdrew FF-68 on 2026-11-09: "we already made a decision about what a decision means, who owns it, and who can make it… it already answers ff-68".

## Decision

The classification's Always list says: "A later decision of the user's replaces an earlier one wherever they disagree, whether or not it names it."

## Consequences

- Amends [decision 0030](0030-one-classification-of-who-decides.md).
- [Decision 0049](0049-measure-2-replaced-by-two-measures.md) applies it to measure 2.
