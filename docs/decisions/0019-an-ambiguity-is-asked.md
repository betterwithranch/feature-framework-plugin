# 0019. An ambiguity is asked

Status: accepted, 2026-10-28

## Context

The Outcome allowed clarity questions only before code starts while also saying the user is asked when blocked by a decision no one made, so an agreed thing with two readings had no rule.

## Decision

Choosing between readings of something agreed or codified, when the reading changes the result, is the user's decision. The user is asked, and the answer is written into the record it clarifies. The work never picks a reading on its own.
