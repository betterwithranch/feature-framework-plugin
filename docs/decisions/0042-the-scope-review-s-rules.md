# 0042. The Scope review's rules

Status: accepted, 2026-11-06

## Context

The user approved these rules as worded (FF-53).

## Decision

1. The document says who the feature is for. 2. Each requirement is a result the user can observe. 3. Each scenario states its starting state, what happens and what passes, as results the user can observe. 4. Each measure is taken on real use and has a target. 5. The statement says what the user gets or how that is judged, not how the agent produces it. 6. The statement sets no definition, rule, threshold or procedure; those belong to a later level. 7. The statement names no place where anything lives: no file, component or tool. 8. The statement excludes nothing from the feature and covers no edge case. Replaces criteria 1 and 2.
