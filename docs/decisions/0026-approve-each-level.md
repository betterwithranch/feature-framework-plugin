# Approve each level

- A level moves on only when its review passes and the user approves it. Approval is the user saying so; a correction, a question or "looks good, but" isn't approval.
- The levels approved this way are Outcome, Behaviour, Design and Slices. Approving Slices lets Build start.
- Approving a level makes everything in it agreed: nothing in it is asked again, except for clarity or to resolve a conflict.
