# 0074. Name a rule by what it checks

Status: accepted, 2026-11-10

## Context

Review files and skills referred to rules by number, which drifts when rules change. The user chose A (FF-75).

## Decision

The writing rules add: "Refer to a rule by its number only where naming what it checks wouldn't say which rule is meant."

## Consequences

- Amends [decision 0070](0070-writing-rules.md).
- The review files and skills name each rule by what it checks. A rule's own list number stays.
