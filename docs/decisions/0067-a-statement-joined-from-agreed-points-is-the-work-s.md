# 0067. A statement joined from agreed points is the work's

Status: accepted, 2026-11-09

## Context

[Decision 0066](0066-provenance-rule-1-a-joined-statement-needs-a-source-per-part.md) let Provenance rule 1 pass a statement that joins several things the user said or agreed. It cited no recorded decision, and the classification says the opposite: a decision that "Follows from something agreed, a codified rule or a goal" is the work's ("The work decides" 1), and the work's statements are marked as its own. So the review round that failed R8 and S8's "about what the current level decides", which joins [decision 0021](0021-play-back-before-acting-interview-before-drafting.md) with [decision 0009](0009-block-lower-level-questions.md), gave the right verdict, and the earlier passes were the misses.

## Decision

- Provenance rule 1 returns to "The statement is something the user said or agreed, or it is marked as the work's."
- R8 drops "about what the current level decides". The limit narrows what [decision 0021](0021-play-back-before-acting-interview-before-drafting.md) says ("Anything that could be read more than one way is put to the user as a choice"), and narrowing an agreement is the user's decision ("The user decides" 2), so R8 returns to 0021's scope.
- S8 keeps "about what that level decides", marked as the work's: it only sets up the scenario's case.
- R8 and S8 also return to what the user agreed on when the choice comes: R8 "after the playback" (FF-14 A, 0021), dropping the unagreed "when there is one"; S8 "after the playback and before its document is written" (FF-20 A, "keep it as written").

## Consequences

- Replaces [decision 0066](0066-provenance-rule-1-a-joined-statement-needs-a-source-per-part.md).
- The Outcome marks words in italics as the work's anywhere in the document, not only in scenarios.
