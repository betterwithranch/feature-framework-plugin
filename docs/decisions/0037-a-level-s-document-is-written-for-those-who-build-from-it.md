# 0037. A level's document is written for those who build from it

Status: accepted, 2026-11-06

## Context

No decision named the reader; asked "Who is a level's document written for?", the user chose FF-47 A: "For those who build from it: neutral voice, a visible ID on every requirement, one requirement per line, a glossary. You approve that same document."

## Decision

A level's document is written for those who build from it: the agents doing later levels, whoever turns its scenarios into tests, and maintainers. It uses a neutral voice ("the user", not "you"). Every requirement, scenario and measure carries a visible ID (R<n>, S<n>, M<n>), stable once approved. Each line states one requirement. It has a glossary of the terms it defines. The user approves that same document.
