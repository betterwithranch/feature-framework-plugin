# 0049. The approved measure 2 is replaced by two measures

Status: accepted, 2026-11-06, the work's decision

## Context

The approved Outcome's measure 2, "Decisions in the code that nothing agreed or codified covers: target zero", predates the classification of who decides ([decision 0030](0030-one-classification-of-who-decides.md)), under which the work makes its own decisions and records them. The classification is a later decision of the user's that disagrees with the measure, so it replaces it ([decision 0061](0061-a-later-decision-replaces-an-earlier-one-it-disagrees-with.md)), and a decision of the user's that replaces an earlier one updates every document that applies the old one. Updating the measure follows from the classification, so it is the work's ("The work decides" item 1).

## Decision

The approved measure is replaced by two: the user's decisions that the work made instead, and the work's decisions that aren't recorded where the user can see them or that became a codified rule. Each has a target of zero.

## Consequences

- Measure 2 applies [decision 0030](0030-one-classification-of-who-decides.md).
