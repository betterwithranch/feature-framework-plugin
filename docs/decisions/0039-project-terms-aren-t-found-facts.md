# 0039. Project terms aren't found facts

Status: accepted, 2026-11-06

## Context

Asked whether a project term the work finds counts as a found fact (FF-49), the user chose A: "No: using a project term with the project's meaning isn't a fact the work found, so every level uses project terms."

## Decision

Using a project term with the project's meaning isn't a fact the work found, so every level uses project terms, including levels that don't allow found facts.
