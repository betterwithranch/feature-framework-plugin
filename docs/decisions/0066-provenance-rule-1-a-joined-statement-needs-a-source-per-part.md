# 0066. Provenance rule 1: a joined statement needs a source for each part

Status: accepted, 2026-11-09

## Context

Provenance rule 1 read "The statement is something the user said or agreed, or it is marked as the work's." R8 limits readings put to the user to those "about what the current level decides"; the limit joins [decision 0021](0021-play-back-before-acting-interview-before-drafting.md), which puts readings to the user, with [decision 0009](0009-block-lower-level-questions.md), which sets questions for a later level aside. Three review rounds passed R8 and S8 on those sources; the fourth failed the same text because no one source holds the whole statement. A verdict that changes on unchanged text is fixed in the rule, not the document.

## Decision

Provenance rule 1 adds: "A statement that joins several things the user said or agreed passes when each part has its own source."

## Consequences

- Amends the Provenance review's rules, [decision 0045](0045-the-provenance-review-s-rules.md).
