# 0046. One project glossary

Status: accepted, 2026-11-06

## Context

The user said "ff-57 would be better served if the glossary was its own doc, referenced by level documents and therefore out of scope for level review. if there are existing rules that would apply to a glossary-only doc, that should be a different review", and answered "ff-58 B".

## Decision

A level's document refers to the project's one glossary instead of holding its own. Level reviews don't judge glossary entries; a separate glossary review owns the rules for it.

## Consequences

- Replaces the glossary clause of [decision 0037](0037-a-level-s-document-is-written-for-those-who-build-from-it.md); the rest of it stands.
