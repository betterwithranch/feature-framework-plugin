# Where found facts live

A fact the work found in the project appears only in a level that allows it:

- Outcome: none. A project fact there means design leaked up.
- Behaviour: only facts about what users get today, where the new behaviour keeps or changes it. Nothing about code.
- Design: the main home. Facts about the code, data, services and interfaces the design builds on.
- Slices: Design's facts carried over, plus facts about how the project is built and tested. No new design facts.
- Build: no document; the code and tests are the record.

In every level that allows them, a fact is marked as the work's, checked against the project by that level's review before the user is asked to approve, and seen by the user at approval. A wrong fact is a finding.
