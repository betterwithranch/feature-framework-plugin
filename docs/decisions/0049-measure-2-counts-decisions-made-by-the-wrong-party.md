# 0049. Measure 2 counts decisions made by the wrong party

Status: accepted, 2026-11-06, the work's decision

## Context

The approved Outcome's second measure, "Decisions in the code that nothing agreed or codified covers: target zero", conflicts with the later agreement that the work makes its own decisions. The user set that agreement on 2026-10-28: "the decisions for what is codified are mine where they need to be mine and not mine where they don't need to be". The user said a conflict with a decision already made is resolved by aligning to it: "If the decision has already been made, then the changes need to be aligned with the decision, and then they won't be in conflict" (2026-11-04).

## Decision

The Outcome's measure 2 counts the user's decisions that the work made, and the work's decisions that aren't recorded where the user can see them or that became a codified rule. Its target stays zero.

## Consequences

- Measure 2 aligns to [decision 0030](0030-one-classification-of-who-decides.md).
