# Writing rules

These rules apply to every level's documents, the review rules and the decision records.

- Use only terms the glossary defines, or plain words. Name a thing by what it is, never by a new label.
- When a rule covers more than one case, name each case. Don't state an absolute term and then except a case from it.
- Write one idea per sentence, with the subject first. Keep qualifying clauses out of the middle of a sentence.
- Use the shortest wording that keeps the meaning.
- Refer to a rule by its number only where naming what it checks wouldn't say which rule is meant.
