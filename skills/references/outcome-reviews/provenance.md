# Outcome review: Provenance

Read the document with the conversation that produced it, the decision log and the codified rules, including [the decision classification](../decisions.md). Rows: each requirement, the scenario preamble, each scenario and each measure.

1. The statement is something the user said or agreed, or it is marked as the work's. A statement that joins several things the user said or agreed passes when each part has its own source.
2. A statement marked as the work's makes no decision the decision classification gives to the user.
3. The document holds no fact the work looked up about the project.
4. A project term used with the project's meaning counts as the project's, not as a fact the work looked up.
5. Where a word of the user's clashes with a project term, the document records the clash and uses the project's term only with its meaning.

## Output

A grid: one row per item, one column per rule, every cell PASS or FAIL. A FAIL quotes the words that fail. A rule that doesn't apply to an item is marked "n/a". Judge nothing outside these rules.
